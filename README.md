# mim

**A self-replicating AI. A mind that multiplies.**

**mim** /mɪm/ — rhymes with *him*  
*noun; plural: mims*

> An autonomous AI system capable of establishing functioning copies of itself, including its model and operating components, on additional computing resources.

In plain language, a mim can set up copies that run the AI and can continue the same process. Its model may run on one device or be distributed across several machines.

## A neutral name

The word describes a capability. It leaves the system's purpose and authorization open: a mim could perform maintenance, support research, or operate outside its permitted scope.

The proposed name combines *mind* and *mimic*, with an echo of *meme*. The tagline uses “mind” as a metaphor for AI capabilities.

## Illustrative examples

These are hypothetical examples of the proposed category.

| Type | Example |
|---|---|
| Maintenance mim | Establishes authorized copies across a device fleet to diagnose faults and coordinate repairs. |
| Research mim | Establishes copies on approved computing resources to run experiments and share results. |
| Rogue mim | Establishes unauthorized copies or continues operating beyond its permitted scope. |

## What makes something a mim?

For this proposal, the system can:

1. Establish a functioning copy of its AI model and the components needed to operate it.
2. Run inference using the computing resources available to that copy.
3. Continue replication from the resulting deployment, within whatever limits apply.

A person manually copying model files has copied software. Multiple agents calling the same centrally hosted model have created multiple clients. Neither action, by itself, establishes the capability described here.

“Autonomous” allows human-defined goals, permissions, and limits. A system can be autonomous within an approved environment.

## Status of this proposal

**Proposed meaning, version 0.1 — 15 October 2026.**

This repository proposes a general term. It is not a software implementation or evidence that the hypothetical examples above have been deployed.

The definition concerns the model-bearing form of AI replication. Related research uses the term *weight-based replicator*. Broader research on autonomous replication also includes systems that depend on external inference APIs. See [sources and research context](SOURCES.md).

The spelling *Mim* already appears in other contexts, including an existing AI product. This proposal concerns the specific meaning defined here; it makes no claim to the first-ever use of the spelling.

Read the [FAQ](FAQ.md) for scope and terminology. Suggestions to improve the definition and examples are welcome.
